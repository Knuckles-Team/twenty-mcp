# Provider workflow catalog

Load only the workflow relevant to the current request.

- [twenty-contacts](../../twenty-contacts/WORKFLOW.md): Manage people (contacts) and companies (accounts) in Twenty CRM through the twenty-mcp tools: find, read, create, update and delete a person or a company with the typed `twenty_*_person` and `twenty_*_company` tools. Use when the agent must find a contact by name or email, look up or create a company, link a person to an employer, or keep account details current. Do NOT use for deals (use twenty-pipeline), for any other object or bulk change (use twenty-records), or for pushing records into the knowledge graph (use twenty-kg-sync).
- [twenty-pipeline](../../twenty-pipeline/WORKFLOW.md): Drive the sales pipeline in Twenty CRM through the twenty-mcp tools: list, read, open, update and delete opportunities with `twenty_get_opportunities`, `twenty_create_opportunity`, `twenty_update_opportunity` and related tools. Use when the agent must triage deals by stage, open a deal for a company, move a deal to a new stage, or change its amount or close date. Do NOT use for people and companies (use twenty-contacts), for other objects (use twenty-records), or for knowledge graph ingestion (use twenty-kg-sync).
- [twenty-kg-sync](../../twenty-kg-sync/WORKFLOW.md): Ingest Twenty CRM records into the knowledge graph with `twenty_ingest_records`: people, companies and opportunities become typed `:Person`, `:Company` and `:Opportunity` nodes linked by `:worksAt`, `:opportunityFor` and `:pointOfContact`. Use when the agent must mirror a workspace into the graph, refresh CRM nodes before a graph query, or make deals and accounts available for cross-source reasoning. Do NOT use for day-to-day changes to contacts or deals (use twenty-contacts or twenty-pipeline); ingestion reads Twenty and writes only to the graph.
- [twenty-records](../../twenty-records/SKILL.md): Read and change any Twenty object, built-in or custom, through the generic record tools: `twenty_get_records`, `twenty_get_record`, `twenty_create_record`, `twenty_update_record`, `twenty_delete_record`, `twenty_find_records`, `twenty_find_duplicates` and the batch tools that create, update or delete up to 60 records per call. Use when the agent works with notes, tasks, custom objects, or any change that touches many records. Do NOT use for people, companies and deals one at a time (use twenty-contacts or twenty-pipeline) or for schema changes (use twenty-metadata).
- [twenty-metadata](../../twenty-metadata/SKILL.md): Inspect and change the Twenty workspace schema through the metadata tools: read objects, fields and relations (`twenty_get_metadata*`), define custom objects, fields and relations (`twenty_create_metadata_*`), update them (`twenty_update_metadata_*`) and drop them (`twenty_delete_metadata_*`). Use when the agent must model a new object, add a field, relate two objects, or audit the schema. Do NOT use for record data (use twenty-records) or for GraphQL queries (use twenty-graphql).
- [twenty-graphql](../../twenty-graphql/SKILL.md): Run GraphQL against a Twenty workspace with `twenty_graphql` and `twenty_execute_gql`, and look up types with `twenty_discover_graphql_schema`. Use when a read or write needs a nested selection, a filter, or an operation the REST record tools cannot express. Do NOT use for simple record reads and writes (use twenty-records, twenty-contacts or twenty-pipeline) or for schema definition (use twenty-metadata).
- [twenty-oauth](../../twenty-oauth/SKILL.md): Handle Twenty OAuth and webhooks: read the server metadata (`twenty_get_oauth_discovery`), register a client (`twenty_register_oauth_client`), exchange or refresh tokens (`twenty_exchange_oauth_token`, `twenty_refresh_oauth_token`), get a server-to-server token (`twenty_client_credentials_oauth_token`) and verify webhook signatures (`twenty_validate_webhook_signature`). Use when an application must sign in to Twenty, renew a token, or trust an incoming webhook. Do NOT use for first-time workspace bootstrap and API key creation (use twenty-provisioner) or for record data (use twenty-records).
